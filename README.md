# ✨ Why DocuMind?

Organizations store critical knowledge across:

* PDFs
* Reports
* Technical documentation
* Spreadsheets
* Web pages
* Scanned images

Finding information is slow.

DocuMind enables users to interact with their content conversationally using Oracle Cloud Generative AI and semantic retrieval.

Instead of searching through documents manually, users simply ask questions and receive context-aware answers grounded in their own data.

# 🚀 Quick Start

## Clone Repository

```bash
git clone https://github.com/anchals0915/DocuMind.git

cd DocuMind
```

## Backend Setup

```bash
python -m venv venv

source venv/bin/activate

pip install -r requirements.txt

uvicorn main:app --reload
```

## Frontend Setup

```bash
cd frontend

npm install

npm run dev
```

Open:

```text
http://localhost:5173
```
